# Vibe

Vibe is a modern offline music player for Android built with Flutter and Dart.

## Features

- Local music scanning from the Android device
- Library browsing by songs, artists, albums, and folders
- Offline search
- Full-screen now playing UI with shuffle, repeat, previous, next, and queue controls
- Favorites and playlists
- Smart resume and last position saving
- Sleep timer and A-B repeat concepts
- Local lyrics support with `.lrc` files and metadata
- Material 3 UI with light and dark mode
- Mini-player and bottom navigation
- Hive-based local storage

## Run locally

1. Install Flutter 3.3+
2. Open the project in Android Studio
3. Run:

```bash
flutter pub get
flutter run
```

## Notes

- The app is designed for Android only.
- It works fully offline and never uses internet streaming or cloud services.
